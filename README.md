# Fermata releases

Build artifacts for the Fermata desktop app. No source lives here.

Download the latest DMG from [Releases](https://github.com/fermata-ai/fermata-releases/releases/latest).
Fermata runs on Macs with Apple silicon.

**First install.** Open the DMG, drag Fermata to Applications, and open it. The app is signed and
notarized by Apple, so macOS asks only whether to open an app downloaded from the internet. Every later
version arrives through the in-app Update button.
