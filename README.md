# Fermata releases

Build artifacts for the Fermata desktop app. No source lives here.

Download the latest DMG from [Releases](https://github.com/fermata-ai/fermata-releases/releases/latest).

**First install:** the app is not code-signed yet, so macOS will not open it on a double click.
Open the DMG, drag Fermata to Applications, then right-click Fermata and choose **Open**, and
**Open** again in the dialog. This is needed once. Every later version arrives through the
in-app Update button.
